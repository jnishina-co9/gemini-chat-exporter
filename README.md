# Gemini Chat Exporter

## 概要
Google Gemini のチャット履歴から、画面上の「いいね（高評価）ボタン」や「共有ボタン」といった不要な文字を自動で取り除き、**純粋な会話文だけを綺麗に抽出・保存できる** Chrome 拡張機能です。

「画像（サムネイル）の保存」や、「Googleドキュメントへの一発貼り付け機能」などを標準搭載し、AIとの会話の「資料化」がグッと楽になります。

すべての処理はお使いのブラウザ内（ローカル）で完結し、外部サーバーへのデータ送信は一切行わないため、機密情報を扱う場合でも安全にご利用いただけます。

## 特徴と機能

### 1. 資料化が数秒で完了！「Copy for Docs」機能
ボタンを押すと、見出しの装飾や画像が綺麗な状態（リッチテキスト形式）のままクリップボードに記憶されます。あとはGoogleドキュメント等を開いて「貼り付け（Ctrl + V）」をするだけで、一瞬でそのまま共有できるレベルの資料が完成します。

### 2. 会話の文脈を逃さない「サムネイル画像の自動保存」
テキストだけでなく、質問のときにアップロードした画像や生成された画像のエクスポートにも対応しています。画像は安全な文字データ（Base64）に変換してファイルの中に直接埋め込んでいるため、インターネットに繋がっていないオフライン環境でも確実に画像を確認できます。

### 3. 読みやすさが格段にアップ！「句点（。）での自動改行」
出力するテキストの句点（。）の後に、自動で改行を挿入する機能を搭載しています。これによって文章に自然な余白が生まれ、後から見返しても内容がスッと頭に入ってくる目に優しいレイアウトになります。

## ボタンの種類と使い方

拡張機能を導入後、Geminiの画面右下に専用のパネルが表示されます。

1. **Load All History**（全履歴の読み込み）
   - 長い会話でもワンクリックで一番上まで自動でスクロールし、隠れている過去のやり取りをすべて読み込んで保存の準備をします。コピーや保存の前にはまずこのボタンを押してください。
2. **Copy for Docs**（ドキュメント用コピー機能）
   - Googleドキュメント用に、画像やレイアウトを維持したまま直接クリップボードにコピーします。
3. **Download MD**（Markdown形式での保存）
   - 純粋な会話のテキストと画像を、プログラマー向けの Markdown (.md) 形式でファイルとして保存します。

## インストール方法（デベロッパーモード）

本ツールはChromeウェブストアを経由しない「デベロッパーモード」での導入となります。

1. 配布ファイル（ZIP等）をダウンロードし、PC内の任意の場所で解凍します。
2. ChromeブラウザのURLバーに `chrome://extensions/` と入力して管理画面を開きます。
3. 画面右上の「**デベロッパー モード**」をオンにします。
4. 画面左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
5. 解凍したフォルダを選択します。
6. 一覧に追加されれば完了です。Geminiの画面（`https://gemini.google.com/app/`）を開き、ページを再読み込みしてご活用ください。

※万が一パネルが表示されない場合は、Chrome 右上にある拡張機能アイコンをクリックし、「**ボタンを表示する**」を選択してください。

## 使う上での注意事項・知っておいていただきたいこと

- **「Download MD」を使う場合、画像の確認にはプレビュー対応エディタが必要です。**
  画像を文字データ（`data:image/jpeg;base64...`）に変換してファイルに埋め込んでいるため、Windowsの「メモ帳」などで開くと、ただの長い文字の塊にしか見えません。画像として確認するためには、VS Codeなどのエディタで開き、「プレビューモード（VS Codeの場合は `Ctrl`+`Shift`+`V`）」に切り替える必要があります。
  ※これが手間に感じる方は、「Copy for Docs」ボタンをぜひご活用ください！
- **画像を含める分、データサイズは少し大きくなります。**
  通常のテキストのみを保存するときと比べ、画像データをそのまま取り込むため、ファイルの容量やクリップボードのデータサイズはどうしても少し大きく（重く）なります。あらかじめご了承ください。
